The Gallery Concept

Designed with intent.
Built with purpose.

A student-led reimagining of the modern storefront — calm, intentional, and premium by design.

The engineer.

My name is Suryansh Dixit. I am a second-semester B.Tech student with Roll No. 2503215400200, pursuing this project as part of my Web Development coursework.

I approached this not as an academic exercise, but as a real product challenge: how do you make something that feels premium without a single external dependency? The answer lives in the fundamentals — HTML semantics, CSS custom properties, hardware-accelerated transforms, and clean vanilla JavaScript state management.

Every interaction — the 3D card tilt, the popover cart drawer, the GST-inclusive checkout calculator — was designed and written by hand, with deliberate care for both the user experience and the underlying code architecture.

Design as a discipline.

The design language borrows from physical gallery spaces: generous white space, natural warm tones, restrained typography pairing a serif display face with a functional sans-serif body — Instrument Serif for what deserves weight, Inter for what needs clarity.

Amazon is not a clone. It is a study in what digital commerce could look like if the designer was allowed to start from zero with only one constraint: it must feel human.

The storefront features live INR pricing mirrored from active Amazon.in categories, real product data, GST-inclusive cart calculations, persistent localStorage state, and a fully responsive layout — all in under 1200 lines of hand-written code.
